# Mode D — Social Media Writer

```
SOURCE IDEA → AUDIENCE → PLATFORM → HOOK → MESSAGE → VALUE → CTA → PLATFORM-NATIVE FORMAT
```

Never paste the same text across platforms. Each one gets its own hook, length, structure and
CTA. Platform limits change — treat the numbers below as working guidance and verify when
precision matters.

| Platform | Native shape | Hook | Length guide | Hashtags | CTA style |
|---|---|---|---|---|---|
| **Facebook** | story / educational / community / offer post | first line before "See more" (~125 chars) | 40–250 words | 0–3 | comment prompt, link in post or first comment |
| **Instagram** | caption for image, carousel copy (slide-by-slide), Reel caption | first line (~125 chars shown) | caption 50–200 words; carousel 6–10 slides, ≤25 words/slide | 3–8 relevant | save / share / DM keyword / link in bio |
| **LinkedIn** | professional insight, founder story, case study | 1–2 lines before "…see more" (~200 chars) | 120–300 words, short paragraphs | 0–3 | question or soft invite; links often better in comments |
| **X** | single post or thread | the post is the hook | ≤280 chars/post (premium longer); threads 4–10 posts | 0–2 | reply / repost / link at end of thread |
| **Threads** | conversational post | first sentence | ≤500 chars | 1 topic tag | reply prompt |
| **TikTok** | hook + short script + on-screen text + caption | first 1–2 seconds, spoken + text | 15–60s script (~40–150 words) | 3–5 | follow / comment keyword |
| **YouTube** | title, description, chapters, script, Shorts script | title + thumbnail text; first 15s of script | title ≤ 60–70 chars; description first 150 chars matter; chapters `00:00` start | 2–3 in description | subscribe, related video, link |
| **Pinterest** | pin title + description (search engine behavior) | keyword-led title | title ≤100, description ≤500 chars | 0–2 | "Read the guide", link to page |

## Rules
- Lead with value or tension, not the brand name.
- One idea per post; one CTA per post.
- Keep claims as accurate as on the website — no fabricated results, testimonials or stats.
- Emojis only if the brand voice uses them; respect the user's voice samples when provided.
- Promotional posts: the offer's real terms only (price, deadline, eligibility) — no fake urgency.
- Accessibility: alt text for images, captions for video, camel-case hashtags (#SmallBusiness).

## Repurposing an article (Social + SEO integration)
```
Blog article → Facebook post → LinkedIn post → Instagram carousel → X thread
→ Short-video script → Pinterest pin → Email newsletter
```
Pull a different angle for each (the stat, the mistake, the checklist, the story, the
before/after), and link back to the canonical article where the platform allows.
